# Petch IT Portfolio

เว็บไซต์แนะนำตัวและรวมผลงานสาย IT โทนสี Navy Blue / Cyan ออกแบบให้รองรับมือถือและคอมพิวเตอร์

## วิธีเปิดดู
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `petch_it_portfolio` ใน VS Code
3. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server
4. แก้ไข `index.html` และ `style.css` ตามต้องการ

## ก่อนเผยแพร่จริง
- แก้ `YOUR_EMAIL@example.com` เป็นอีเมลจริงของคุณ
- เปลี่ยนลิงก์ GitHub ไปยังโปรไฟล์ของคุณ
- เพิ่ม URL เดโมและ repository จริงของแต่ละโปรเจกต์
- ตรวจสอบรายละเอียดชื่อ สถานศึกษา และประสบการณ์ให้ตรงกับข้อมูลจริง
- ภาพตัวอย่างผลงานเป็น CSS mockup ไม่ใช่ภาพหน้าจอจริง

## ไฟล์
- `index.html` เนื้อหาและโครงสร้าง
- `style.css` ธีมสีน้ำเงินและ responsive layout
- `script.js` เมนูมือถือ ปุ่มคัดลอกอีเมล และปีใน footer
